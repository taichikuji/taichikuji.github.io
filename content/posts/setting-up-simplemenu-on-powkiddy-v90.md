## Setting up SimpleMenu

To get everything working, SimpleMenu needs to be set up as intended. This is the short version of the process.

First, thanks to [Riksmeet's guide](https://github.com/rik-smeets/powkiddy-bittboy-wiki/wiki/Custom-firmware-skins-%26-SimpleMenu) and [Jahed's guide](https://jahed.dev/2022/01/25/improving-powkiddy-v90-ux/), which made this setup possible. I compiled a SimpleMenu archive for this guide as well.

1. Download the archive from the [SimpleMenu releases section](https://github.com/taichikuji/simplemenu/releases/) and extract it to `/mnt/apps/simplemenu` on the V90's SD card.

   **Important for macOS users:** after copying the `simplemenu` folder into `apps`, open `/mnt/apps/simplemenu/scripts/autoexec.sh` and uncomment the line beginning with `find /mnt/`. This cleans the dot files generated by macOS from the SD card on every boot.

2. Unplug the SD card from the computer and insert it into the V90.

3. Turn on the system and press `R1` or `L1` to switch menus until you find the Applications menu.

4. Open the `Explorer` app.

5. Navigate to `apps` -> `simplemenu` and run `deploy.sh`.

6. Wait a few seconds while the script applies the changes. The device will shut down when it is finished.

7. Turn the device on again. If everything went correctly, it should boot directly into SimpleMenu.

Happy gaming!
